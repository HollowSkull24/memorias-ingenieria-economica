# Definición

> **Según la NIC 1 – Presentación de Estados Financieros:**  
> *El Estado de Situación Financiera (Balance General) presenta los activos, pasivos y patrimonio de una entidad a una fecha determinada.*

El **Balance General** es un **informe contable que muestra la posición financiera de una empresa en un momento específico del tiempo**, es decir, **qué posee (activos), qué debe (pasivos)** y **el valor neto que pertenece a los propietarios (patrimonio)**.

> 📅 Mientras el [[Estado de Resultados]] mide la rentabilidad *durante un periodo*,  
> el **Balance General** muestra la *situación a una fecha determinada* (por ejemplo, 31 de diciembre de 2025).

---

# Estructura básica del Balance General

El Balance General se organiza en tres grandes grupos contables:

| Elemento | Descripción | Ejemplos | Nota relacionada |
|-----------|--------------|-----------|------------------|
| **[[Activos]]** | Recursos controlados por la empresa que generarán beneficios futuros. | Efectivo, inventarios, propiedades, cuentas por cobrar. | [[Activos]] |
| **[[Pasivos]]** | Obligaciones presentes derivadas de eventos pasados. | Préstamos, cuentas por pagar, impuestos por pagar. | [[Pasivos]] |
| **[[Patrimonio]]** | Valor residual de los activos una vez deducidos los pasivos. | Capital social, reservas, utilidades retenidas. | [[Patrimonio]] |

---

# Ecuación fundamental de la contabilidad

> 🧮 **Activos = Pasivos + Patrimonio**

Esta ecuación representa el **principio base del sistema contable**:  
todo lo que posee una empresa (**activos**) ha sido financiado ya sea con **deudas (pasivos)** o con **inversiones de los dueños (patrimonio)**.

---

# Clasificación general de cuentas

## 💰 **Activos**
- **Corrientes:** efectivo, inventarios, cuentas por cobrar.  
- **No corrientes:** propiedades, planta y equipo, activos intangibles, inversiones a largo plazo.  
> Ver nota: [[Activos]]

## 💳 **Pasivos**
- **Corrientes:** obligaciones a menos de un año (proveedores, préstamos, impuestos).  
- **No corrientes:** deudas de largo plazo, arrendamientos financieros.  
> Ver nota: [[Pasivos]]

## 📈 **Patrimonio**
- Capital aportado, utilidades retenidas, reservas, resultados del ejercicio.  
> Ver nota: [[Patrimonio]]

# Ejemplo de presentación (forma vertical)

| **BALANCE GENERAL - Empresa TechCol S.A.** | **Al 31 de diciembre de 2025** |
| ------------------------------------------ | ------------------------------ |
| **ACTIVOS**                                |                                |
| Efectivo y equivalentes                    | $10,000,000                    |
| Cuentas por cobrar                         | $5,000,000                     |
| Inventarios                                | $4,000,000                     |
| Propiedades, planta y equipo               | $12,000,000                    |
| **Total Activos**                          | **$31,000,000**                |
|                                            |                                |
| **PASIVOS**                                |                                |
| Cuentas por pagar                          | $6,000,000                     |
| Préstamos bancarios a corto plazo          | $3,000,000                     |
| Deudas a largo plazo                       | $5,000,000                     |
| **Total Pasivos**                          | **$14,000,000**                |
|                                            |                                |
| **PATRIMONIO**                             |                                |
| Capital social                             | $10,000,000                    |
| Utilidades retenidas                       | $7,000,000                     |
| **Total Patrimonio**                       | **$17,000,000**                |
|                                            |                                |
| **TOTAL PASIVOS + PATRIMONIO**             | **$31,000,000** ✅              |

> 💡 *La ecuación contable se cumple: Activos = Pasivos + Patrimonio.*
